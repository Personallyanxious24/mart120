Cli (command Line Interface) and GUI (Graphical User Interface) are distinct but necessary tools when interacting with a computer system or software. Gui has a graphical component to it, files and such are layed out nice and neat. An example is your file explorer keeping documents organized and clean. However, precision is limited. While Cli more or less has the same component's; Cli is a type-based interface in which your able to code exactly what you want. The difference is layout and attention to detail. While the layout of a gui may be more suitable for a wide arrangement of people, Cli is essential in scripting your own system brick by brick.
